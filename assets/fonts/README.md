# Fonts

The show's own typefaces, self-hosted so no visitor data goes to a font service. All are free under the [SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/).

| File | Font | Copyright | Changes |
|---|---|---|---|
| `limelight.woff2` | Limelight (headings; the masthead's TOMORROW) | Copyright (c) 2010 by Sorkin Type Co, with Reserved Font Name Limelight | Converted to WOFF2 only |
| `anton.woff2` | Anton (verdict stamps, as on screen) | Copyright 2020 The Anton Project Authors | WOFF2, Latin-1 subset |
| `courier-prime-bold.woff2` | Courier Prime Bold (datelines and labels; the masthead tagline) | Copyright 2015 The Courier Prime Project Authors | WOFF2, Latin-1 subset |

Limelight has a Reserved Font Name, so it is shipped whole rather than subset.
