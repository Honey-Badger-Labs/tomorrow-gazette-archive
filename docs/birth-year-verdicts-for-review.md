# Dot's verdicts: for the editor to review

Every verdict below marked **PROPOSED** is the newsroom's suggestion. None of them has aired. Until you approve them, the page and the share cards print "Draft verdict · awaiting the editor's OK" on these.

To change one, edit `verdict` / `reason` for that `id` in `tools/build_data.py`, then run `python3 tools/build_data.py`.
